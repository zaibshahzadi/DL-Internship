# Deep Learning Internship
# About This Repository

This repository contains the projects, hands-on exercises, and practical work completed during my **Deep Learning Internship**.

During this internship, I followed a structured learning roadmap based on the **Learn → Apply → Build** approach. I developed a practical understanding of Deep Learning fundamentals and implemented different neural network architectures using real-world and synthetic datasets.

The internship covered three major areas:

* Neural Network Foundations
* Convolutional Neural Networks (CNNs)
* Sequential Models including RNNs, LSTMs, and GRUs

The purpose of this repository is to document my Deep Learning learning journey and showcase the practical implementations and projects completed during the internship.
# Internship Goals

By the end of the internship, the main goals were to:

* Understand Deep Learning fundamentals
* Understand the structure and working of neural networks
* Implement MLP models for classification
* Build neural networks from scratch using NumPy
* Implement Deep Learning models using TensorFlow/Keras
* Understand Convolutional Neural Networks
* Perform image classification using CNNs
* Apply dropout and batch normalization
* Understand sequential data and sequence modeling
* Implement RNN, LSTM, and GRU models
* Work with real-world and synthetic datasets
* Visualize model performance and predictions
* Evaluate and improve Deep Learning models
